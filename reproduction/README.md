# FVI reproduction — 2025 Gyeongsangbuk-do mega-wildfire

Full, reproducible re-analysis of the **Fire Vulnerability Index (FVI)** — a
physics-based, pre-fire fire-**hazard** index (IPCC Hazard component) combining
topography, meteorology and fuel — applied to the 2025 Uiseong–Andong mega-wildfire,
and validated against a **Sentinel-2 dNBR** burn-severity map.

This package rebuilds every layer from real source data (the original analysis
rasters were lost) and supersedes the manuscript's press-based validation.

## Headline results (re-analysis)

| Item | Manuscript (original) | Re-analysis (this package) |
|---|---|---|
| Validation target | press-based perimeter (~3,300 ha) | **Sentinel-2 dNBR** perimeter (**61,637 ha**) |
| Natural-Breaks GVF | 0.9491 | **0.9450** |
| ROC AUC | 0.602 | **0.712** |
| Grades 4+5 share of burn | 54.6% (in 40.1% area) | **79.9%** (in 50.9% area) |
| Damage concentration by grade | 0.34→…→1.45 | **0.07→0.18→0.68→1.32→1.85** (monotonic) |
| Weight sensitivity (AUC) | — | 0.693–0.721 (stable) |
| Fuel ±10% (AUC) | — | 0.706–0.712 (stable) |
| Coniferous vs broadleaf burn rate | — | **22.0% vs 8.5%** (conifer = 62% of damage) |

AHP-documented weights (CR = 0.000): topography 0.30 / meteorology 0.30 / fuel 0.40;
sub-weights slope 0.50 / aspect 0.30 / elevation 0.20 and eff.humidity 0.40 /
wind 0.40 / temp 0.20.

## Analysis grid

EPSG:5186, 30 m, **3233 × 3033 = 9,805,689 cells**, top-left (326000, 481000) —
identical to the manuscript. See `config/grid.json`.

## Pipeline (`scripts/`)

```
01_topography.py  --dem <DEM>                 -> topography.tif   (slope/aspect/elev, AHP 50/30/20)
02_fuel.py        --sheets-dir <landcover>    -> fuel.tif         (corrected MOE code map)
03_meteorology.py --asos-csv <ASOS.csv>       -> meteorology.tif  (eff.humidity/wind/temp, IDW)
04_fvi.py                                      -> FVI.tif, FVI_grade.tif (Natural Breaks, GVF; Table 3)
05_dnbr.py        --pre <dir> --post <dir>     -> dNBR/severity/burn_perimeter.tif
06_validation.py                               -> AUC + Table 4 (concentration by grade)
07_sensitivity.py                              -> weight & fuel AUC sensitivity
08_forest_overlay.py                           -> forest-type x burn (species vs severity)
```

Run 01–03 (any order), then 04, then 05, then 06–08. Steps 05–08 read the
`*.npy`/`*.tif` written by earlier steps in the working directory.

## Important correction

The earlier `config/fuel_scores.csv` (root of repo) mis-mapped the MOE mid-level
code scheme — codes 610/620 (bare land) and 710/720 (water) were swapped, and
160/240/250 were missing — which would turn water into fuel and bare land into a
firebreak. `config/fuel_scores_corrected.csv` fixes this to the actual 22-class
scheme, aligned with manuscript Table 1.

## Notes / caveats

- Validation is restricted to the Sentinel-2 covered swath (539,192 ha), which
  fully contains the burn scar; the un-imaged north/south strips are excluded.
- Pre (Mar 14) vs post (Apr 8) spring green-up adds dNBR noise in farmland; the
  burn core uses dNBR ≥ 270 with a ≥ 9 ha connected-component filter.
- DEM substituted (NGII, EPSG:5174) for the manuscript's SRTM; meteorology uses
  13–14 ASOS stations vs the original 8. Numbers therefore differ from — and
  improve on — the originals.
