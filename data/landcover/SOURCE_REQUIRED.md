# 환경부 중분류 토지피복 원자료 필요

FVI의 연료인자 재생성과 연료점수 민감도 분석에는 연구영역 전체를 덮는 **환경부 중분류 토지피복도**의 원 도엽이 필요하다. 현재 이 폴더에는 원 토지피복 파일이 포함되어 있지 않다.

## 공식 입수 경로

- 환경공간정보서비스 자료신청 안내: <https://aid.mcee.go.kr/req/intro.do>
- 토지피복지도 안내: <https://aid.mcee.go.kr/intro/land.do>

공식 안내에 따르면 온라인 자료신청은 로그인 사용자가 신청서 등록 후 신청내역에서 내려받는 절차이며, 공개제한 자료는 공문 신청·방문 수령 절차가 적용될 수 있다. 중분류 토지피복지도는 1:25,000 도엽 단위로 제공된다.

## 반입 기준

| 항목 | 요구사항 |
|---|---|
| 권장 형식 | 원본 SHP 전체 구성파일(`.shp`, `.shx`, `.dbf`, `.prj`, `.cpg`) 또는 공식 GeoTIFF |
| 제작시점 | 2025년 사건창에 가장 가까운 공식 제작연도. 원고의 실제 사용연도와 다르면 그 차이를 명시 |
| 공간 범위 | 의성·안동·청송·영양·영덕 등 실제 분석 extent 전체를 덮는 도엽 |
| 필수 기록 | 제작연도, 도엽번호, 원 분류코드, 신청번호/취득일, 출처 URL, 이용조건 |
| FVI 연결 | 모자이크 → EPSG:5186 → 30 m 공통격자 rasterize → `config/fuel_scores.csv`의 점수와 결합 |

## 파일명 규약

```text
landcover/
├── moe_landcover_medium_YYYY_<sheet>.*
├── provenance_landcover_YYYY.json
└── SOURCE_REQUIRED.md
```

허가가 재배포를 허용하지 않거나 파일이 대용량이면 원자료를 이 Git 저장소에 올리지 않는다. 대신 `provenance_landcover_YYYY.json`과 SHA-256, 도엽목록, 재실행 가능한 전처리 로그만 커밋한다.
